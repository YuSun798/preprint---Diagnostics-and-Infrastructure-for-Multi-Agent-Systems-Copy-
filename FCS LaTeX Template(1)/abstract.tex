Foundation model-based multi-agent systems (MAS) introduce reliability requirements that span execution tracing, failure attribution, safety intervention, and serving-time resource management. Existing reviews typically analyze these functions separately. This evidence-aware critical review maps representative diagnostic methods and serving systems along explicit axes: required evidence, replay and training demands, attribution granularity, intervention timing, state compatibility, workload assumptions, and runtime cost. We distinguish functional roles from implementation strategies, and correct ambiguous method classifications. A central question is when serving-state reclamation impairs later diagnosis. We show that evicting a KV cache is not equivalent to deleting a diagnostic trace: interference arises only when evidence or a non-reconstructable execution dependency shares a constrained resource, is actually discarded, and is needed within the diagnostic horizon. We therefore formulate a \emph{conditional retention trade-off} as a testable design hypothesis rather than an established universal conflict. Finally, we outline an instrumented, replay-capable evaluation protocol with matched reliability and serving metrics. The resulting synthesis highlights verifiable architectural interfaces and open questions without ranking non-comparable systems or claiming that a joint optimization has already been empirically demonstrated.
