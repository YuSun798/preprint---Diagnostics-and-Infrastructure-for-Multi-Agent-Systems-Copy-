\noindent O2: Cross-layer benchmarks. The benchmark gap identified in Section 4.4 is particularly\par
\noindent acute for cross-layer evaluation. A cross-layer benchmark would need four components that\par
\noindent currently exist in isolation: (a) a realistic multi-agent workload generator (TraceElephant [6]\par
\noindent provides 220 failures from production systems but no serving-side workload); (b) a config-\par
\noindent urable serving backend with tunable eviction policy and memory pressure; (c) injected failures\par
\noindent at known locations for ground-truth attribution; and (d) matched diagnostic and serving metrics\par
\noindent measured simultaneously. The closest existing infrastructure is the TRAIL benchmark [10],\par
\noindent which uses OTel-format traces architecturally compatible with serving-side telemetry. Extend-\par
\noindent ing TRAIL to include serving-side OTel spans (cache hit/miss events, eviction decisions) would\par
\noindent create the first cross-layer dataset. However, TRAIL’s low baseline accuracy (∼11\%) suggests\par
\noindent that cross-layer evaluation may be premature until single-layer attribution reaches higher accu-\par
\noindent racy.\par
\par\smallskip
\noindent O3: Scalability of training-free methods. MASPrism’s [19] 0.6B-parameter signal-extraction\par
\noindent approach achieves competitive accuracy at dramatically lower cost than frontier-model methods\par
\noindent (2.66s vs. 105 min for FAMAS). Whether this paradigm scales to longer trajectories, multi-\par
\noindent agent coordination failures (37\% of MAS failures per TrajAudit §IX), and heterogeneous ar-\par
\noindent chitectures remains open. The approach relies on the assumption that prefill-stage NLL and at-\par
\noindent tention signals carry diagnostic information — an assumption that may weaken for distributed\par
\noindent coordination failures. A promising direction is combining lightweight signal extraction with\par
\noindent targeted LLM reasoning: use MASPrism-style filtering to identify candidate failure regions\par
\noindent cheaply, then deploy CHIEF-style hierarchical analysis only on the narrowed candidate set.\par

\noindent O4: Observability standards for multi-agent state. The OpenTelemetry GenAI conven-\par
\noindent tions [25] cover LLM inference spans but lack serving-side attributes: cache residency, eviction\par
\noindent events, memory pressure, adapter loading. The proposed agentic extensions (Issue \#35) remain\par
\noindent at Todo status. Extending the standard would enable three capabilities: (a) diagnostic sys-\par
\noindent tems detecting when evidence is at eviction risk; (b) cross-layer benchmarks using standardized\par
\noindent telemetry; and (c) automated DRICE I-dimension assessment. The implementation challenge\par
\noindent is frequency: serving events occur per-token while diagnostic events occur per-failure, so ag-\par
\noindent gregate attributes (cache utilization, eviction rate) are more practical than per-token instrumen-\par
\noindent tation.\par
