\noindent 6.9 Counterexamples: When Eviction Does Not Harm Diagnosis\par
\noindent To sharpen the conditional nature of the cross-layer relationship, we enumerate cases where\par
\noindent KV-cache eviction explicitly does not create an evidence-loss event:\par
\noindent  1. Independent trace storage. When diagnostic traces are stored in a log database or ob-\par
\noindent  ject store separate from GPU memory, KV-cache eviction has no effect on diagnostic\par
\noindent  availability. This is the default architecture for 16 of 22 infrastructure systems and all T1\par
\noindent  failure-localization methods.\par
\noindent  2. Deterministic environments. When tool responses are deterministic (same input always\par
\noindent  produces same output) and the input is logged, any lost KV state can be recomputed from\par
\noindent  the prompt text. The recomputation cost is a Tier B effect (increased latency), not a Tier C\par
\noindent  effect (information loss).\par
\noindent  3. Post-hoc attribution. 10 of 12 failure-localization methods operate on completed tra-\par
\noindent  jectories after the task has finished. By the time attribution runs, the KV cache for that\par
\noindent  task has typically already been evicted. These methods read from logs, not from GPU\par
\noindent  memory.\par
\noindent  4. Prefix-sharing under exact match. SGLang’s radix tree and Mooncake’s distributed\par
\noindent  pool serve the same text to multiple requesters without any diagnostic state being embed-\par
\noindent  ded in the cached prefix. Evicting a shared prefix forces recomputation for future requests\par
\noindent  but does not destroy any agent-specific diagnostic information.\par
\noindent  These counterexamples explain why the cross-layer conflict is empirically uncommon de-\par
\noindent spite the theoretical possibility: current systems are architected to avoid it.\par
