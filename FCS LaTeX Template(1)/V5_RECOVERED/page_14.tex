\noindent Supervised methods. Two systems use task-specific supervised training rather than RL or\par
\noindent LLM prompting:\par
\noindent  Xia et al. [40] propose a multi-perspective verification approach with adaptive refinement\par
\noindent (COLM 2026). A judge LLM generates a failure hypothesis, multiple independent evalua-\par
\noindent tor LLMs verify it from different viewpoints (structural, temporal, semantic), and confidence-\par
\noindent weighted voting aggregates their assessments. The evaluator feedback is then used to fine-tune\par
\noindent the judge via LoRA (rank 64, α=128, dropout 0.05, 3 epochs). This iterative judge-evaluator\par
\noindent loop reaches 69.05\% agent-level accuracy on algorithm-generated scenarios, competitive with\par
\noindent AgenTracer’s RL approach. A key efficiency advantage: the system uses only 451K tokens\par
\noindent per attribution on algorithm-generated scenarios versus AgenTracer’s 16.4M tokens — a 36×\par
\noindent reduction — at \$0.063 versus \$2.275 per case (§5).\par
\noindent  StepFinder [52] takes a different supervised approach, using a BiLSTM with agent-aware\par
\noindent attention and multi-scale differencing on top of Qwen3-Embedding-0.6B features (KDD 2026).\par
\noindent The system is trained on LLM-prompted trajectory regeneration data (1,564 algorithm-generated\par
\noindent and 2,604 hand-crafted trajectories, up to 50 epochs). At inference, StepFinder produces zero\par
\noindent output tokens — it generates a step-level attribution from the learned representations without\par
\noindent any LLM decoding. Inference time is 0.61s on algorithm-generated scenarios versus 2.92s\par
\noindent for the best LLM baseline, running on a single NVIDIA RTX 3080 Ti (Table 6, §7). Accu-\par
\noindent racy is modest at 29.63\% (algorithm-generated) and 22.99\% (hand-crafted), below LLM causal\par
\noindent methods, but the approach demonstrates that lightweight learned attributors can operate at <1s\par
\noindent latency.\par
